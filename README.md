# BAE AR Lab

A modular Vite + React + TypeScript foundation for experimenting with real-time beauty AR and face-warp algorithms.

## Stack

- Vite
- React
- TypeScript (strict)
- ESLint
- Prettier

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run format`

## Current Scope

This initial setup includes a 4-panel lab layout:

- Source Preview
- Processed Preview
- Control Panel
- JSON Output

Not yet implemented:

- camera input
- MediaPipe integration
- WebGL rendering
- shader execution
